# Projeto-Pousada
Sistema de gerenciamento de pousada desenvolvido em Java como projeto de aprendizagem. O projeto aplica Programação Orientada a Objetos (POO), permitindo cadastrar, listar, editar e buscar hóspedes, gerenciar quartos por categoria e disponibilidade, além de criar, consultar e cancelar reservas por meio de um menu interativo no console.
